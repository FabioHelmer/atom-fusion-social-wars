# Atom Fusion — Guia de Social Wars

Este é um **guia não oficial feito por fã**, sem vínculo com a Social Point ou a FB Games Web. Ele reúne combinações de Atom Fusion relatadas pela comunidade, organiza as fusões por pré-requisitos e permite marcar as unidades que você tem para filtrar as receitas.

Abra o [Atom-Fusion.html](Atom-Fusion.html) no navegador. As marcações do inventário ficam salvas no próprio navegador.
